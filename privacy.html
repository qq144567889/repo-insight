隐私政策

适用扩展：Repo Insight（开源项目解读器）｜ 最近更新：2026-09-28

1. 我们不收集任何数据

本扩展没有自建服务器，不统计使用行为，不上报崩溃日志，不含任何第三方分析或广告 SDK。

2. 数据存在哪里

数据存放位置说明
模型 API Key、GitHub Token本机浏览器 chrome.storage.local明文保存在本地配置文件；已限制为仅本扩展页面可读，但仍建议使用最小权限的 Key
仓库信息与 README 缓存本机浏览器默认保留 6 小时；私有仓库内容不写入缓存
生成的 Markdown仅当前弹窗内存关闭弹窗即丢弃，除非你主动复制或下载

3. 数据会发送到哪里

触发动作发送内容接收方
点击「生成解读」仓库名称、元信息、根目录文件列表、README 文本（最多 30000 字符）api.github.com，以及你在设置页选择的模型服务商
模型选择 Ollama同上仅本机 localhost:11434，内容不离开本机
私有仓库提示：当你配置了有权限的 GitHub Token 并打开私有仓库时，README 内容会被发送至所选模型服务商。 默认情况下扩展会逐次询问确认；你也可以在设置页永久关闭该行为，或切换为仅本地运行的 Ollama。 请根据所在组织的合规要求决定是否使用云端模型。

4. 你的控制权

  • 设置页可随时查看、修改、清空 API Key 与 Token；
  • 「清除所有本地数据」会删除设置、缓存与进行中状态；
  • 「清除缓存」只删除仓库信息缓存，保留配置。

5. 生成内容的性质

解读文档由第三方大模型生成，可能存在错误、过时信息或不适用于你环境的步骤。扩展会在文档顶部标注 AI 生成的标识。执行任何部署命令前，请核对仓库官方 README 与发布说明。

6. 权限用途说明

权限用途
storage在本机保存设置与仓库信息缓存
activeTab读取当前标签页地址，判断是否为仓库页面
api.github.com、各模型服务域名调用对应接口获取仓库信息、生成解读
可选域名权限仅当你选择「自定义 Base URL」时，按需向你填写的域名申请访问权限

7. 卸载后的数据处理

本扩展完全运行在浏览器沙箱内：不修改操作系统设置（不含注册表、plist、启动项、系统服务、环境变量）， 也不写入浏览器之外的任何文件，只使用扩展专属存储 chrome.storage.local。 卸载扩展时，Chrome 会自动删除该扩展的专属存储，因此不会留下系统级残留。 如需在卸载前主动清理，可使用设置页的「导出历史备份」「清空历史」与「清除所有本地数据」。

8. 联系方式

如有隐私相关问题，请联系扩展维护者（上架信息中提供的邮箱）。
