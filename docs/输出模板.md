## 本地降级版（未配置模型 / 模型调用失败）

章节结构与模型版一致，标题改为 `# {仓库名} 项目深度解读（本地模板 · 未接入 LLM）`，内容为仓库信息、技术栈探测、许可证提示与部署骨架，并在元信息区标注降级原因。

## 结构自检

生成后会校验六个必需章节是否存在、顺序是否正确：

- 校验通过 → 正常显示；
- 校验失败 → 预览区顶部提示「模型输出未完全匹配模板（缺少章节：…）」，可重新生成。

扩展**不会**自动改写模型输出的章节结构（自动改写容易破坏正文逻辑），只做提示。

## 字段规范（提示词内已内建）

| 字段 | 要求 | 禁忌 |
|---|---|---|
| 一句话定位 | ≤30 字，说清"是什么 + 解决什么问题" | 营销话术 |
| 定位与核心功能 | 先 2-4 句定位，再逐条功能 | 编造 README 没有的功能 |
| 架构说明 | 分层 / 模块 / 数据流 / 技术栈 | 臆测内部实现 |
| 短板风险 | ≥3 条，覆盖五个维度，每条具体到现象 | "有待完善"这类空话 |
| 适合 / 不适合 | 按真实能力边界，成对出现 | 写成广告 |
| 部署工作流 | 四段式，命令必须可执行 | 不确定处未标注「需查阅 README 确认」 |
| 总结 | 2-3 句 + 明确评级 | 不给评级 |
