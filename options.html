⚙️ Repo Insight 设置

所有配置只保存在本机浏览器（chrome.storage.local），不会上传到任何服务器。
模型服务
必须使用 https（本机地址可用 http）。保存时会请求该域名的访问权限，否则请求会被浏览器拦截。
选择 Ollama 时无需填写。仓库元信息与 README 会随请求发送给所选服务商。
GitHub 访问
不填也能用（匿名 60 次/小时）。只为提升配额时，Token 不需要任何写权限：
推荐用 Fine-grained token，Repository access 选 Public Repositories (read-only)； 不要使用 repo（全量私有仓库读写）或 public_repo（公开仓库读写）。
隐私与数据
默认关闭。关闭时，遇到私有仓库会逐次询问；选择 Ollama 则完全不外发。
私有仓库不会被缓存；缓存只存在于本机，可随时清除。
交互与输出
精简模式生成时间约减半，但可能省略部分细节；章节结构保持不变。
同一标签页同一地址只弹一次。若浏览器拒绝自动弹出（例如窗口未聚焦），会改为在扩展图标上显示角标 ✦ 提示。 自动弹出需要读取标签页地址，为此申请了 https://github.com/* 域名权限（比申请全量 tabs 权限更窄）。
默认关闭。关闭时许可证限制会写进「短板、坑点与风险」章节的条目里，保持与输出模板一致的章节结构（不增删章节）。
文档结构：一句话定位 → 项目定位与核心功能 → 架构说明 → 短板、坑点与风险（重点）→ 适合 / 不适合人群 → 一键部署工作流 → 总结（含评级）。
数据与隐私
同一仓库只保留最新一条；超过 20 条或 5 MB 时自动淘汰最旧记录。
默认关闭：私有仓库的解读不会写入本地历史。

关于卸载：本扩展完全运行在浏览器沙箱内，不修改操作系统设置，也不写入浏览器之外的文件； 卸载时 Chrome 会自动删除扩展专属存储（含 API Key、Token 与历史记录），因此不会留下系统级残留。 保险起见，可以先「导出历史备份」，再执行「清除所有本地数据」。
